# Direção visual

O FIN é o protagonista recorrente. A cena deve funcionar primeiro como imagem estática: ideia única, leitura imediata, hierarquia clara e continuidade de identidade.

Motion deve apoiar a narração, não competir com ela. Use zoom lento, pan sutil, fade, mask reveal e transições curtas. Morph, gráficos e SVGs entram somente quando o conteúdo exigir.

O pipeline abstrato baseado em composições SVG, golden snapshots e famílias de layout foi encerrado. Não recrie seus contratos no caminho ativo.
